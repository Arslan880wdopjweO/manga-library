Описание проекта

MangaShelf — учебная онлайн-библиотека манги для читателей, которым нужно быстро посмотреть произведения по жанрам и познакомиться с авторами. Целевая аудитория — студенты и любители манги. Цель сайта — показать базовые возможности HTML и CSS через единый тематический проект. В проекте используются несколько связанных страниц с общей навигацией и подвалом.

Проверка критериев

  • HTML + отдельный CSS-файл.
  • h1/h2/h3, paragraphs, ordered и unordered lists.
  • Изображения с alt и минимум две внешние ссылки.
  • Element, class и ID CSS selectors.
  • Backgrounds, fonts, margins, padding, borders, border-radius.
  • Hover-эффекты для ссылок и кнопок.
  • Float-based layout на странице каталога без Flexbox/Grid.
  • Таблица с nth-child, highlight-row и colspan.
  • Форма с name, email, select, radio, textarea и submit.
  • Адаптивность для небольших экранов.
