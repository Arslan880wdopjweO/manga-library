## Файлы
- `index.html` — Task 1: HTML/CSS introduction + profile card.
- `catalog.html` — Task 2: layout с `float` (без Flexbox/Grid).
- `tribute.html` — Task 3: tribute page об Осаму Тэдзуке.
- `stats.html` — Task 4: CSS table.
- `feedback.html` — Task 4: feedback form.
- `project.html` — Task 5: описание проекта, sitemap и wireframe.
- `styles.css` — общий CSS.
- `*.svg` — локальные изображения.
