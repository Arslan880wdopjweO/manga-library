# MangaShelf — Assignment #1

Учебный сайт-библиотека манги по требованиям Assignment #1 HTML & CSS Basics.

## Файлы
- `index.html` — Task 1: HTML/CSS introduction + profile card.
- `catalog.html` — Task 2: layout с `float` (без Flexbox/Grid).
- `tribute.html` — Task 3: tribute page об Осаму Тэдзуке.
- `stats.html` — Task 4: CSS table.
- `feedback.html` — Task 4: feedback form.
- `project.html` — Task 5: описание проекта, sitemap и wireframe.
- `styles.css` — общий CSS.
- `*.svg` — локальные изображения.

## Запуск
Откройте `index.html` в браузере.

## GitHub Pages
1. Создайте GitHub repository.
2. Загрузите все файлы из этой папки.
3. Убедитесь, что главный файл называется `index.html`.
4. В Settings → Pages выберите публикацию из ветки с файлами.
5. Откройте выданный адрес GitHub Pages.

## Примечание
Форма является демонстрационной и не подключена к серверу.
